# AI 基建研究工作流

本文档定义如何最大化使用 topkyo AI 基建研究台：它是一级信息过滤器和研究复盘工具，不是自动交易系统，也不生成可直接执行的投资建议。

核心目标：

- 从 AI 基建股票池中减少漏看，快速暴露行情、估值、预期、数据质量和持仓变化。
- 每日只沉淀 5-6 只值得深入讨论的候选标的。
- 用 LLM 或炼丹炉做二级研究对话，重点找证据、反证、缺失数据和失效条件。
- 最终结论由人工复核产生，任何目标仓位都只作为注意力排序和组合压力测试参考。

## 每日一级过滤

先看首页 `/`，再跑 `/signals`。

首页用于快速筛选：

- 主题环节：光模块、AI 服务器、液冷、电力、IDC、存储、半导体设备与材料等。
- 全球供应链：优先识别和海外 AI capex 直接相关的标的。
- 现价与一致预期：关注隐含上行、买入一致比例和无法获取数据的标的。
- 数据错误：任何失败、延迟或非实时标记都进入复核清单，而不是忽略。

`/signals` 用于候选排序：

- 优先关注 `open`、`add`、`trim`、`exit`，它们代表组合层面的变化。
- 对已有持仓，重点看当前仓位、目标仓位、调仓差额、浮盈亏和失效条件。
- 对新标的，重点看 `targetWeight`、`confidence`、`evidence`、`risks`、`invalidation`。
- 对所有标的，必须检查 `dataQuality` 和 `fundamentalFieldSources`。

目标仓位不等于交易指令。它只用于回答：今天哪些标的值得优先花研究时间。

## 候选 5-6 只入池规则

候选池不追求覆盖全部机会，只追求当日最值得研究的少数问题。

入池优先级：

- `adjustedTargetWeight > 0` 且 `confidence` 较高。
- `open` 或 `add`，并且证据不是泛化叙事。
- 已有持仓出现 `trim` 或 `exit`，因为这直接影响组合风险。
- 同一细分方向出现多个强信号时，只保留代表性最强的 1-2 只。
- 至少覆盖 2-3 个产业环节，避免候选全部来自单一拥挤方向。

降级或剔除条件：

- `missing_fundamental`、`missing_profit_yoy`、`missing_peg` 等关键字段缺失且无法快速补证。
- LLM 的 `evidence`、`risks`、`invalidation` 无法对应到真实字段或外部材料。
- 只有短期涨幅，没有基本面、主题景气或事件催化支撑。
- 数据源显示非实时、失败或明显异常，且该数据会影响判断方向。

候选池建议结构：

| 类别 | 数量 | 目的 |
|---|---:|---|
| 主线进攻 | 2 | 当日最强主题或景气方向。 |
| 持仓复核 | 1-2 | 已有仓位是否加、减、退出。 |
| 风险预警 | 1 | 强信号但数据或事件风险不完整。 |
| 反向观察 | 1 | 被市场忽视、估值修复或低拥挤方向。 |

## 二级 LLM/炼丹炉深聊

对每只候选构造同一套研究包，不让 LLM 自由发挥。

研究包字段：

- 基础信息：代码、名称、主题、是否全球供应链。
- 项目输出：动作、目标仓位、调整后目标仓位、置信度、理由、证据、风险、失效条件。
- 数据状态：PE(TTM)、PB、市值、利润同比、PEG、近 30 日价格、20 日动量、数据质量标记、字段来源。
- 持仓上下文：当前仓位、目标仓位、调仓差额、浮盈亏、现金约束。
- 人工补充：最近公告、财报、订单、客户、产能、解禁、减持、问询函、产业链价格、券商研报原文摘录。

二级讨论使用固定角色：

- 多头分析师：说明为什么值得进研究队列。
- 空头分析师：找最可能错的地方。
- 风控经理：评估仓位、波动、流动性、拥挤度、事件风险。
- 数据审计员：指出哪些结论缺证据、哪些字段不可用、哪些必须查原文。

禁止事项：

- 不允许 LLM 编造公告、订单、客户、调研或券商观点。
- 不允许把“市场可能预期”当成事实证据。
- 不允许在关键数据缺失时给出确定性结论。
- 不允许直接输出“买入/卖出”作为最终动作。

## 二级研究 Prompt 模板

把候选研究包贴到 `【输入】` 后使用。

```text
你是一组中国 A 股 AI 基建研究员，不是交易下单系统。请基于我提供的数据做研究复核，不要编造任何未给出的公告、订单、客户或研报内容。

目标：判断该标的是否进入今日 5-6 只深度研究候选，并明确需要人工补证的关键问题。

请按四个角色分别输出：

1. 多头分析师
- 最强的 3 条支持证据。
- 这些证据分别来自输入中的哪个字段或材料。
- 如果证据不足，明确写“证据不足”。

2. 空头分析师
- 最强的 3 条反证或风险。
- 哪一条最可能推翻多头假设。
- 需要查哪些公告、财报或产业链数据来验证。

3. 风控经理
- 当前信号更像进攻、持有复核、减仓复核还是风险预警。
- 若进入研究队列，建议的人工观察点和失效条件。
- 不输出可直接执行的交易指令。

4. 数据审计员
- 列出缺失字段、非实时数据、来源不可靠或口径可能错配的地方。
- 标记哪些结论不能在当前数据下成立。

最后给一个结构化结论：
- 研究等级：重点研究 / 观察 / 风险预警 / 暂不跟踪
- 核心假设：最多 3 条
- 关键反证：最多 3 条
- 必查材料：最多 5 项
- 今日下一步：查资料 / 等公告 / 加入观察 / 人工估值 / 暂时放弃

【输入】
```

## 复盘闭环

每次二级讨论后保留一条人工记录：

- `date`：研究日期。
- `symbol`：标的代码。
- `level`：重点研究 / 观察 / 风险预警 / 暂不跟踪。
- `thesis`：核心假设。
- `evidence`：已验证证据。
- `counter_evidence`：反证或风险。
- `missing_data`：未覆盖数据。
- `invalidation`：失效条件。
- `follow_up`：下一次复核时间或触发条件。

复盘只评估研究质量：

- 当时哪些数据缺失但被忽略。
- LLM 是否强化了单边叙事。
- 人工补证后结论是否反转。
- 5/10/20 个交易日表现是否验证了研究假设，而不是证明策略必然有效。

## 合规与边界

- 本项目不接券商接口，不自动下单，不处理真实资金划转。
- 回测只用于复盘研究流程，不用于证明未来收益。
- 自动化投资工具和 AI 投资叙事存在误导风险，使用时必须保留人工判断和证据审计。
- 若未来进入程序化交易或自动交易范畴，需要另行建设交易申报、风控、异常监测、错误处理和人工干预机制。
