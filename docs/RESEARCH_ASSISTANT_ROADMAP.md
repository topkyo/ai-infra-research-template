# 个人研究辅助路线图

本文档定义项目下一阶段方向：topkyo AI 基建研究台只做个人研究辅助，用于发现研究线索、暴露数据质量、沉淀复盘记录；不作为交易系统、自动下单系统或投资建议生成器。

## 定位

- 只产出研究线索，不产出可直接执行的交易指令。
- `buy` / `hold` / `sell` 后续只作为历史兼容标签，新能力统一使用关注等级。
- 固定关注等级：`重点研究`、`观察`、`风险预警`、`暂不跟踪`。
- 回测和历史表现只用于校准研究流程，不用于宣传收益或证明未来有效性。
- 人工复核是最终入口，系统只负责减少漏看、暴露数据坑、提升复盘一致性。

## 下一阶段目标

优先交付 `研究队列 v1`，把每日输出收敛为少量高质量候选：

- 默认只给出 5-10 个 `重点研究` 标的。
- 每个重点标的必须包含支持证据、风险/反证、数据质量状态。
- 风险数据缺失时必须显示 `未覆盖` / `unavailable`，不得生成泛化风险来伪装完整。
- 历史表现区域必须标注局限：点时数据未完成前，不把回测收益作为策略有效性证据。

验收标准：任一重点标的都能回答“为什么进入今日研究队列、哪些数据支持、哪些风险已覆盖、哪些数据不可用”。

## 核心能力

### 证据链

每个研究建议都绑定可审计输入：

- 估值：PE(TTM)、PB、利润增速、PEG 或缺失原因。
- 动量：20 日涨跌幅、趋势状态、异常涨跌幅。
- 主题：所属环节、是否全球供应链、主题分层。
- 数据质量：字段来源、缓存/实时状态、warning、unavailable。
- 结论依据：LLM 使用了哪些关键字段，而不是只给一句叙事。

### 风险与反证

研究辅助不能只强化看多叙事。风险层优先覆盖：

- 减持、解禁、问询函、监管处罚、业绩预告不及预期。
- 商誉、应收账款、存货、现金流等财务质量风险。
- 订单证伪、客户集中度、海外限制、供应链不确定性。
- 估值极端、短期拥挤、放量滞涨、连续大涨后的回撤风险。

未接入的数据源必须显式标记 `未覆盖` / `unavailable`。不得用 LLM 猜测、模板话术或缓存结果合成风险结论。

### 历史展示防误导

历史回看会影响判断，必须显式暴露局限：

- 历史调仓日可能使用当前基本面。
- 当前股票池回放历史会产生幸存者偏差。
- LLM 可能带有调仓日之后的信息，`as_of` prompt 不能完全隔离。

在点时数据、历史股票池和无前视评估完成前，历史表现只作为研究流程复盘材料。

## 后续增强

- 信号稳定性：记录重复运行一致率、模型分歧、关注等级变化、首次出现和结论反转。
- 主题拥挤度：板块内同涨比例、短期涨幅、成交额放大、涨停/跌停数量。
- 事件日历：财报、业绩预告、解禁、股东大会、重大公告。
- 股票池分层：核心龙头、弹性观察、周期修复、主题投机、低波动观察组。
- 快照后跟踪：记录信号后 5/10/20 个交易日表现，只用于复盘研究质量。
- 人工工作台：待看、已读、重点跟踪、暂时排除、需复核、研究笔记和结论历史。

## 不做事项

- 不接券商接口，不做自动交易，不处理真实资金。
- 不新增表现拟合或自动调参目标。
- 不把未经点时修正的回测收益展示为策略能力。
- 不增加业务兜底：LLM、API 或关键数据失败时仍保持显式失败。
- 不用规则、模板、缓存或 LLM 猜测合成投资结论来掩盖失败。
